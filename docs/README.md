| Guide | Use it when you want to… |
| --- | --- |
| [Usage](USAGE.md) | Run, inspect, steer, review, and clean up child agents |
| [Configuration](CONFIGURATION.md) | Change monitoring, scheduling, resource, or UI defaults |
| [Troubleshooting](TROUBLESHOOTING.md) | Diagnose installation, tmux, queue, recovery, or cleanup problems |
| [Updating](UPDATING.md) | Upgrade Pi or the extension safely and roll back if needed |
